# EMK850+ 低功耗分析仪 · 串口驱动 + HTTP 接口

逆向英加（Yingjia）EMK850+ 串口协议，提供 Python 命令行工具与普通 FastAPI HTTP 服务。脚本、CI 或 AI 助手可通过 HTTP 读取 µA/nW 级功耗并驱动可编程输出，打通 AI 低功耗优化闭环。

![英加 EMK850+ 低功耗分析仪](docs/emk850_photo.jpg)

## 项目亮点

- **核心痛点解决**：分析仪锁定在 Windows 图形界面、无开放 API，AI 与脚本无法驱动，自动化闭环被阻断。
- **深度协议逆向**：复现 115200/8N1 串口协议、64 字节定长帧、0x33 帧头、0x40 延续帧分片。
- **比原厂更稳健**：逐字节流式帧同步状态机；原厂按 64 字节对齐块读取会丢尾帧，本项目错位时仅丢 1 字节即可重新同步。
- **开箱即用接口**：Python 命令行 + HTTP 服务；脚本、CI 与 AI 可直接读取功耗并驱动输出。
- **真实工程价值**：可作可编程电源，在调试器无法连接时给休眠 MCU 断电复位。

## 功能特性

- **精密功耗读取**：实时 V/I/P，分辨率达 µA/nW。
- **可编程输出**：0-3.3V 可调，可给休眠芯片断电复位。
- **空载清零**：扣除浮空基线，读数更干净。
- **HTTP 暴露**：每项能力都是 HTTP 接口，便于自动化与 AI 调用。

## 快速上手

### 命令行读取功耗

```bash
uv sync
python emk850_analyzer.py power COM19
```

```text
电压: 4.202 V   电流: 6.94 uA   功耗: 29.2 uW
```

### 启动 HTTP 服务

```bash
python emk850_mcp_server.py --port COM19 --http 8000
```

普通 FastAPI HTTP 服务（非 MCP 协议）。启动后访问 `http://localhost:8000`；任何 HTTP 客户端均可调用，脚本、CI 或 AI 助手都行。

| 端点 | 方法 | 说明 |
|---|---|---|
| `/power?sample_s=0.8` | GET | 读功耗（V/I/P，自动 启动→采样→停止） |
| `/output` | POST | 设输出：`{"state":"on","voltage":3.3}` 设 3.3V，`{"state":"off"}` 设 0mV |
| `/clear` | POST | 空载清零，需 `{"confirm":true}` |
| `/version` · `/config` · `/health` | GET | 版本 / 校准参数 / 服务与设备状态 |
| `/start` · `/stop` | POST | 手动开始 / 停止采样 |

## 典型实战：唤醒休眠 MCU

低功耗调试常遇到这个问题：MCU 进入深度休眠、调试器无法连接。可用仪器作可编程电源断电复位：

1. 关闭输出：`POST /output {"state":"off"}`
2. 等待 10-15 秒电容放电
3. 恢复 3.3V：`POST /output {"state":"on","voltage":3.3}`
4. 芯片复位，调试器重新连接

> 注：`"off"` 通过设 0mV 间接拉低输出（协议无直接关断命令）。0mV 时测量端仍读约 2.6V；在认定 DUT 真正掉电前，请用万用表确认。

## 协议关键信息

- 串口：**115200 / 8N1**
- 帧结构：固定 **64 字节**，帧头 `0x33`，`0x40` 延续帧分片
- 避坑：不要照搬原厂 64 字节对齐块读取（会丢尾帧）。用逐字节流式状态机，错位仅丢 1 字节即可重新同步。

完整命令表、数据换算公式详见：[docs/EMK850_PROTOCOL.md](docs/EMK850_PROTOCOL.md)

## 注意事项

- **串口独占**：HTTP 服务占用串口，不要同时运行原厂上位机或命令行工具。
- **清零有风险**：分析仪输入必须浮空（无 DUT）。带设备清零会把其电流基线归零。
- **档位限制**：分析仪自动换挡；未校准档位（om=0）电流无法换算，相关采样会被跳过。
